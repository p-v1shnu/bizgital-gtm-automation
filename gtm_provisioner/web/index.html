สร้าง GTM Container สำหรับร้านใหม่

กรอกแค่ชื่อร้านกับโดเมน ระบบจะสร้าง GA4 property, Meta pixel และ GTM container ที่ตั้งค่าครบพร้อม publish ให้

ใช้ตั้งชื่อ Meta pixel เป็น “<ชื่อร้าน> - Dataset”

ใช้เป็นชื่อ GTM container และ GA4 property ใส่ https:// มาได้ ระบบตัดให้

ตัวเลือกเพิ่มเติม

Meta ลบ pixel ไม่ได้ ถ้ามี pixel เหลือที่ยังไม่ได้ใช้ ใส่ ID ตรงนี้ ระบบจะเปลี่ยนชื่อแล้วใช้ต่อ ถ้าเว้นว่างจะสร้างใหม่
